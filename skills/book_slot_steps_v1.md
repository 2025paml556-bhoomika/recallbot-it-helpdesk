# Booking a desk-side visit (v1)

Follow these steps in order. Ask one question per turn, and never skip ahead.

1. Make sure you know where the engineer should come: the office, the floor, and the desk. If any of that is missing, ask: "Which office, floor, and desk should the engineer come to?"
2. Ask which day works, unless the user already named one.
3. Ask what time of day works, unless the user already named one.
4. Once the place, the day, and the time are all known, read them back and ask "Shall I book that visit?" Do not write anything yet.
5. Write the visit only after the user agrees. A "no", or a change of subject, writes nothing.
6. A fault report uses the same three questions. The ticket and the visit are written together on the turn the user agrees, not on the turn the fault was first described.
7. Changing an existing visit asks only for the part that is changing, then confirms again before the row is updated.
