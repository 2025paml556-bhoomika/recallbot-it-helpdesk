# Authenticator Setup and Recovery

This note is the how-to companion to the password policy. The policy decides the rules; this note describes the steps.

## Enrolment

1. Install the authenticator app from the software portal on the company phone, or on a personal phone if no company phone was issued.
2. On a laptop, open the security page on the intranet and choose Add sign-in method.
3. Scan the code with the app and approve the test push.
4. Save the ten fallback codes into SW-PWM-01. Each code works a single time.

Enrolment is part of the first morning for a new joiner and is assisted by the buddy.

## Daily use

VPN, webmail and the portals send a push. Approve it with biometrics or the app PIN. A push that you did not request should be denied, and then reported to the service desk, because it means someone else has the password.

## New phone

Install the app on the new phone, then contact the service desk for a video call. The desk verifies the employee number and the manager's name, revokes the old enrolment and walks through a fresh one. Until that call, the fallback codes still work. Do not try to move the account by exporting it yourself; the app's backup does not restore the work account.

## Lost fallback codes

The desk can issue a fresh set of ten during the same video check. The old set stops working the moment the new set is created.
