# Software Requests

## The catalogue

Software is installed from the company portal, not from vendor websites. The portal shows three lists. The standard list installs with no approval. The managed list installs after the manager approves in the same portal. Anything absent from both lists needs a new-software request.

Standard examples are the Cisco AnyConnect client SW-VPN-AC, the password manager SW-PWM-01, and the Office suite SW-OFFICE-365. Managed examples are the design suite SW-DESIGN-04 and the database IDE SW-DBIDE-02.

## New software

A request for software the catalogue does not hold uses the code SW-REQ-112. The form asks for the business reason, whether the tool stores company data, and whether a current catalogue item already does the job. The security review takes ten working days. Buying a licence personally and claiming it back is not permitted.

## Admin rights

Standard laptops do not have local administrator rights. Most portal installs run without them. A tool that genuinely needs admin rights is requested under SW-REQ-112 and, if approved, is installed by the service desk rather than by granting the user those rights.

## Removal and licence recovery

Unused managed software is reclaimed after 90 days with no launch. The user is emailed fourteen days before the licence returns to the pool. Reinstalling from the portal is immediate if a licence remains free.
